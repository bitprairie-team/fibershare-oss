# Security

## Reporting a vulnerability

Please report security problems privately through GitHub's
[Report a vulnerability](https://github.com/bitprairie-team/fibershare-oss/security/advisories/new)
form on this repository's Security tab. Do not open a public issue for them.

Include what you found, how to reproduce it and the impact you expect.
We aim to acknowledge reports within a few days.

This repository is a demo with sample data only. It holds no real herd, location or account data.

Bugs that are not security problems can go in a normal issue.
